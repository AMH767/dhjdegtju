# SCALP-AI — бот 24/7 для GitHub Pages

Сайт-терминал (`index.html`) работает, только пока открыта вкладка браузера — так устроен JavaScript. Чтобы торговля шла **постоянно**, в комплекте есть бот для **GitHub Actions**: GitHub сам запускает его на своих серверах каждые 5 минут, даже когда ваш компьютер выключен.

## Что делает бот

- Каждые 5 минут анализирует топ-20 USDT-перпетуалов Bybit: стакан, дельта агрессора, FVG, снятия ликвидности, тренд 1м/5м/15м, новости и вол-радар (PUMP/DUMP-импульсы, приоритет волатильных монет).
- Ведёт виртуальный счёт: **старт 30 USDT → цель 500 USDT**, риск 1% на сделку с компаундингом, кросс-маржа, плечо до x10, частичный тейк 50% + безубыток, самообучение весов после каждой сделки.
- Сохраняет состояние в **`bot/state.json`** и каждую закрытую сделку дописывает в **`bot/history.txt`**, после чего коммитит оба файла в репозиторий.
- Сайт на GitHub Pages читает `bot/state.json` раз в минуту и показывает депозит, позиции, кривую капитала, историю сделок и уроки ИИ — с пометкой «Режим 24/7».

## Установка (5 минут)

1. Откройте свой репозиторий (где уже лежит сайт).
2. Нажмите **Add file → Upload files** и загрузите:
   - `index.html` — обновлённый файл терминала (из этой сборки),
   - папку `bot/` с тремя файлами: `bot.js`, `state.json`, `history.txt`,
   - `README.md` (этот файл, по желанию).
3. Создайте папку workflow: **Add file → Create new file**, в поле имени введите
   `.github/workflows/trade.yml` (GitHub сам создаст папки) и вставьте содержимое файла `trade.yml` из этой сборки.
4. Нажмите **Commit changes**.
5. Включите Actions: вкладка **Settings → Actions → General → Actions permissions → Allow all actions** (обычно включено по умолчанию).
6. Проверьте: вкладка **Actions** → слева «trading bot 24/7» → зелёные галочки каждые несколько минут.

Всё. Дальше бот торгует сам и обновляет `state.json`/`history.txt` в репозитории.

## Где что смотреть

| Что | Где |
| --- | --- |
| Сайт со статистикой бота | `https://логин.github.io/репозиторий/` |
| Журнал сделок (history.txt) | вкладка репозитория → `bot/history.txt` |
| Текущий счёт и открытые позиции | `bot/state.json` (поле `acc` / `open`) |
| Логи каждого запуска бота | вкладка **Actions** → запуск → «Trade» |

## Важно знать

- GitHub Actions запускает cron «каждые 5 минут» **с задержкой** — иногда 5–15 минут между запусками. Это ограничение GitHub, так и задумано: бот каждый раз проверяет позиции по свежим свечам 1м и ничего не пропустит.
- Коммиты от имени `scalp-bot` появляются в истории репозитория — это нормально (журнал ведётся прямо в репо). Коммит делается при закрытых сделках и раз в 30 минут как «heartbeat».
- Бот виртуальный (paper): реальные ордера не отправляются, счёт — симуляция по реальным ценам. Достижение 500 USDT не гарантировано — это испытание риск-профиля, а не обещание доходности.
- Начать заново с 30 USDT: удалите `bot/state.json` через интерфейс GitHub (и очистите строки сделок в `bot/history.txt`, если хотите чистый журнал).
- Права на запись workflow получает через встроенный `GITHUB_TOKEN` (permissions: contents: write уже прописаны в `trade.yml`) — отдельно создавать ключи не нужно.
